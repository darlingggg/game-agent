# 对话工具过程验收记录

日期：2026-10-10（北京时间）。按要求完成快速验收，耗时较长的真实服务联调列在下方，供后续验收。

最后验收约 17 分钟，超过原定 10 分钟。其中一次打包因 Windows 占用生成的 `components.d.ts` 失败，重试后构建通过。下面明确区分已通过的检查和交给后续验收的项目。

## 已实现

- 实时工具调用按正文位置穿插，每种已注册工具有独立 SVG 图标，悬浮/键盘聚焦显示展开箭头；参数、结果、错误和耗时可折叠查看。
- 生图任务按独立调用 ID 关联到工具详情；取消自动插入助手正文的大图卡片。
- Markdown 图片和图片链接显示 40px 缩略图入口，点击打开完整图片查看器；已有生图引用可刷新签名地址。
- 重进会话默认显示折叠摘要，展开后读取持久化记录，不重新执行工具。没有记录的旧会话只回显正文。
- 聊天内图片进度订阅为只读，历史查看不会重新启动图片生成任务。
- 暗色 `.markdown-content code` 使用主题底色、文字和边框，支持长路径及中文文案换行；代码块不叠加行内代码边框。
- 本地 `localhost/gameagent` 已执行 `pnpm db:migrate:tools`，新增 `message_tool_calls` 表。其他环境需执行同一迁移。

## 快速验收结果

1. 前端构建、类型检查、目标 ESLint 和差异格式检查通过。
2. 前端状态测试 3 项通过：乱序结果关联、文字与工具顺序、停止保留已完成结果。
3. 后端测试 14 项通过，包含真实 MySQL 连接独享临时表和 HTTP 鉴权测试，无跳过项；覆盖调用持久化、幂等、权限、历史摘要、SSE 快照、取消和只读图片观察。
4. 实际前端配合本地验收数据：5 次调用按开始顺序显示，乱序结果属于正确调用；底部旧提示框数量为 0。
5. 实际前端图片检查：正文缩略图为 40×40；工具详情图片限高 120px；生成图未自动出现在正文上方；完整查看器收到刷新后的签名地址。
6. 刷新会话后工具明细默认隐藏，只显示摘要；点击可加载 5 项记录并展开对应生图结果。
7. 点击停止后工具显示“已停止”，该消息的工具加载动画数量为 0。
8. 暗色行内代码实际颜色为浅色文字、主题深色底色，长文案 `overflow-wrap: anywhere`，不再显示亮色条块。

数据库测试使用临时表隔离实际项目数据；前端浏览器验收使用确定性的本地工具事件和参考图片，不调用真实模型或收费生图服务。
